# Capability: xi-sources-cache-prestage

## ADDED Requirements

### Requirement: Pure-eval reader

The capability MUST provide a reader that returns the string value of a flake
attribute via
`nix eval --no-write-lock-file --extra-experimental-features
'nix-command flakes' --apply toString <ref>#<attr>`
and treats any non-zero exit as a `Missing` reply.

Impure flags (`--impure`, environment allowing IFD) MUST be rejected; the reader
is pure-eval only.

#### Scenario: Pure eval on a flake with substituters

- **GIVEN** a flake exposing
  `nixosConfigurations.host.config.nix.settings.substituters =
  ["https://cache.example"]`
- **WHEN** the reader is called with that attribute path
- **THEN** the returned string is exactly `https://cache.example`

#### Scenario: Pure eval refuses IFD

- **GIVEN** a flake attribute whose evaluation would require
  import-from-derivation
- **WHEN** the reader is called
- **THEN** it exits non-zero WITHOUT falling back to `--impure`

### Requirement: Attribute path discovery

The capability MUST try the following attribute paths in order and use the first
that evaluates:

1. `nixosConfigurations.<host>.config.nix.settings`
2. `darwinConfigurations.<host>.config.nix.settings`
3. `homeConfigurations.<user>@<host>.config.nix.settings`
4. `homeConfigurations.<host>.config.nix.settings`
5. `nixCache.settings` (flake-level fallback for home-manager-only repos)

If all five fail the capability returns `status: Missing` and MUST NOT write any
file.

#### Scenario: Home-manager-only flake uses fallback

- **GIVEN** a flake that exposes
  `homeConfigurations.alice.config.nix.
  settings.substituters` and no
  NixOS/darwin configs
- **WHEN** prestage runs for user `alice`
- **THEN** the third attribute path matches and its substituters are prestaged

#### Scenario: No attribute path found returns Missing

- **GIVEN** a flake with none of the five attribute paths present
- **WHEN** prestage runs
- **THEN** no `xi.conf` is written and the status is `Missing`

### Requirement: Atomic write with `!include` amend

Successful prestage MUST write a single file `xi.conf` containing:

```
# generated by xi sources cache prestage
extra-substituters = <space-separated list>
extra-trusted-public-keys = <space-separated list>
```

The containing directory is `/etc/nix/` (system) or `${XDG_CONFIG_HOME}/nix/`
(user). The write is atomic (temp file + rename).

`nix.conf` MUST be amended with a single `!include xi.conf` line only if that
exact line is not already present. The amend uses an atomic read-modify-write.

#### Scenario: Idempotent amend

- **GIVEN** `nix.conf` already contains `!include xi.conf`
- **WHEN** prestage runs twice
- **THEN** `nix.conf` is unchanged across both runs

### Requirement: System-scope daemon reload

On system scope, after a successful write, the capability MUST reload the
nix-daemon so that the next build consults the new substituters. On user scope
no reload is required (Nix reads `~/.config/nix/nix.conf` per invocation).

#### Scenario: Daemon reload after write

- **GIVEN** system scope prestage runs with changes to xi.conf
- **WHEN** the write succeeds
- **THEN** `systemctl reload nix-daemon` is invoked
- **AND** `nix show-config | grep '^substituters'` reflects the new value within
  5 seconds

### Requirement: Declared-key safety guard

For each `trusted-public-key` returned by the reader, the capability MUST verify
the key's fingerprint by fetching it over HTTPS from the hostname of its
matching substituter URL. A mismatch or unreachable host MUST refuse the write.

`--trust-declared-keys` bypasses this verification; invoking it MUST print a
stderr warning naming each untrusted key.

#### Scenario: Unverifiable key refused by default

- **GIVEN** a prestaged key whose fingerprint cannot be fetched from the
  substituter host
- **WHEN** prestage runs without `--trust-declared-keys`
- **THEN** no file is written and the exit code is non-zero

### Requirement: Reversible receipt

A receipt file at `/var/lib/xi/cache-receipt.json` (system) or
`${XDG_STATE_HOME}/xi/cache-receipt.json` (user) MUST record:

- Path to the amended `nix.conf`
- Path to the written `xi.conf`
- SHA-256 of `nix.conf` BEFORE the amend (for integrity check on unstage)
- Timestamp

`xi sources cache unstage` MUST:

1. Verify the sha256 matches the current `nix.conf` minus the single
   `!include xi.conf` line.
2. Remove the `!include xi.conf` line atomically.
3. Delete `xi.conf`.
4. Reload nix-daemon on system scope.

If the sha check fails, unstage MUST refuse (the user edited `nix.conf` in the
interim).

#### Scenario: Unstage reverses to byte-identical nix.conf

- **GIVEN** a prestage was performed and the user has not edited `nix.conf`
  since
- **WHEN** `xi sources cache unstage` runs
- **THEN** `nix.conf` is byte-identical to its pre-prestage state
- **AND** `xi.conf` no longer exists
